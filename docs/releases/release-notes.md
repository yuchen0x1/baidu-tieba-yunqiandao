## V7.5.0：安全与正确性升级

GitHub 发布：2026-11-13。

- 二阶 SQL 注入（高危）：插件配置的贴吧关键词（AI 回帖/自动回帖/帖子监控/封禁）可触发 UNION/盲注读取整库。`findFid`/`mSetFid` 改参数绑定 + 关键词白名单。
- 容器数据暴露：Caddy 默认将 `data/`（含 SQL 备份、日志）、`tools/`、`setup/*.sql` 对外提供。新增访问控制规则封禁私密路径。
- 敏感配置加密：18 个选项（通知 Token、SMTP 密码、OAuth Secret 等）加密落库，页面只显示掩码。空提交保持不变，需显式清空。

## V7.4.0：凭据掩码与恢复校验等安全加固

GitHub 发布：2026-11-08。

- BDUSS/STOKEN 默认掩码：百度账号列表不再把完整凭据写进 HTML 源码，默认显示首尾各 4 位的掩码形态。点「显示」才向服务端按需取回一次明文（管理员会话 + CSRF + 账号归属校验），点「隐藏」立即从内存清除。凭据不再随页面源码、浏览器缓存、屏幕共享与截图外泄。
- 计划任务密码不再出现在页面：签到看板的「立即执行全部签到 / 立即复签失败贴吧 / 手动健康度检查」以及计划任务页的「运行全部计划任务」，改为走管理员会话 + CSRF 的服务端入口（新增 `admin:sign` 白名单分支与 `admin:cron&runall`）。长期密码不会再落进 Web 访问日志、反向代理日志与浏览器历史。
- metrics 端点只接受请求头：`metrics.php` 移除 `?token=` 查询参数认证，仅接受 `Authorization: Bearer` 与 `X-API-Token`。检测到旧用法时返回 403 并附迁移指引与 Prometheus 配置示例，便于一次性切换。

## V7.3.1：更新通道限流回退与部署可靠性修复

GitHub 发布：2026-11-07。

- 匿名限流回退：GitHub API 达到匿名请求限额（HTTP 403/429）时，自动回退读取官方仓库 Release 页面发现最新版本，并按发布脚本固定资产命名获取 Windows 部署包与 SHA-256 校验文件；域名白名单、DNS/重定向逐跳校验与安装前强制摘要校验全部保留，无可信摘要绝不覆盖安装。
- 限流提示明确化：检查更新与立即更新失败时区分限流场景，显示预计恢复时间、`UPDATE_GITHUB_TOKEN` 提升限额建议与 Release 页手动更新入口，不再笼统提示“无法连接更新服务器”。
- do.php --loop 优雅重载（可选，默认关闭）：部署方设置环境变量 `LOOP_RELOAD_FILE` 后，升级完成会写入重载标记，常驻进程在本轮调度结束后退出（退出码 75），由 s6/systemd/任务计划等进程管理器自动拉起加载新代码；未配置时行为不变，仍需手动重启。Web 进程不执行任何命令、不挂载 Docker socket。
