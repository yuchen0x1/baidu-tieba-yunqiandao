# 更新历史

本页汇总产品更新；版本发布资产以 [GitHub Releases](https://github.com/yuchen0x1/baidu-tieba-yunqiandao/releases) 为准。

## V7.6.0 · 2026-11-13

- 计划任务新增搜索、状态筛选、分页历史和手机端纵向布局，查找失败原因与日常操作更直接。
- 修复配置加密后计划任务密码和全局代理密码不可用的问题；自动执行遵守最新启用、到期状态。
- 按任务设置重试预算，改进异常恢复与失败反馈；中文、emoji 和序列化配置的备份恢复更兼容。
- 管理任务变更需使用页面表单；从 7.5.0 升级无新增数据库结构迁移，仍需版本同步与常驻进程重启。
