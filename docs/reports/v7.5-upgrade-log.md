### 阶段 1：P0-1 容器与 Apache 暴露面封禁

**问题**：Caddy 配置 `root * /var/www` + `file_server`，无任何 deny 规则；`.dockerignore` 未排除 `data/`、`tools/`、`setup/*.sql` 等。默认 Docker 部署下 `https://站点/data/backups/dbbackup_xxx.sql` 可直接下载整站数据库。

**修改**：
- 新建 `docker/Caddyfile`：独立配置文件，`respond @private 404` 封禁 `data/*`、`tools/*`、`tests/*`、`docs/*`、`upgrade-report/*`、`official-service/*`、`vendor/*`、`setup/*.sql`、`setup/*.template.*` 等路径
- `docker/Dockerfile`：改为 `cp` 外部 Caddyfile + `sed` 替换 `$WORKDIR` + `caddy validate`，移除内联 echo
- `.dockerignore`：排除 `data/log`、`data/backups`、`tools`、`tests`、`upgrade-report`、`docs`、`official-service`、`*.sql`（保留安装模板）
- 新建 `data/.htaccess`、`data/index.html`、`tools/.htaccess`、`tests/.htaccess`、`setup/.htaccess`（Apache 部署等价防线）
- `tests/ReleaseConfigTest.php`：+4 个回归测试

**验证**：`ReleaseConfigTest` 14 tests / 113 assertions 通过

### 阶段 2：P0-2 二阶 SQL 注入修复

**问题**：`misc::findFid($kw)` 直接 `WHERE tieba = '{$kw}'` 拼串；插件配置的贴吧关键词来自普通用户（AI 回帖、自动回帖、帖子监控、封禁），cron 进程以全库权限执行，可 UNION/盲注读出 `options` 表中的 `crypto_key`，进而解密所有 BDUSS。

**修改**：
- `lib/security.php` 新增 `normalize_forum_keyword()`：trim → 去控制字符 → 长度 ≤ 60 → 白名单 `/^[\p{Han}A-Za-z0-9_+\-·]{1,60}$/u`
- `lib/class.misc.php`：
  - `findFid()`：pquery 参数绑定 + 关键词规范化
  - `mSetFid()`：pquery 参数绑定 + fid 强制 (int)
  - `getFid()`：入口规范化 + 返回值 (int)
  - `getTable()`：补 `safe_table_name()` 白名单
  - `DoSign_All()`：删除 `$kw = addslashes($kw)`

**验证**：164 tests 通过

- `plugins/weltolk_sign_qq/cron_weltolk_sign_qq.php` 与 `weltolk_sign_qq_public.php`：`date("Y-m-") . latest` 拼接改为直接比较 `Y-m-d`
