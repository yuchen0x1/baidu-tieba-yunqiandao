## 四、发现的问题

### 本次修复的 Bug

1. **Session 函数命名冲突**：`lib/session.php` 初版定义了 `function session_destroy()` 与 PHP 内置函数同名，会导致 fatal error。已改名 `session_destroy_all()`。

2. **option::set 缓存转义不一致**：已在 2026-11-12 工作树增量修复为 `pquery` upsert + 原始值缓存，并新增回归测试；`option::add/uset/uadd` 仍待后续收敛。

3. **PHP 内置函数 shadowing**：`session_destroy()` 与内置函数冲突。教训：新增辅助函数时应检查与 PHP 内置函数的命名空间。
