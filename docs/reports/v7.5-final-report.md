## 一、项目原始情况

百度贴吧云签到系统是一个 PHP 8.2+ 自托管 Web 应用（321 跟踪文件 / 223 PHP 文件 / 约 4.29 万行），支持多用户多百度账号、计划任务/常驻循环双调度、签到记录/分析/健康度、通知中心、开放 API、16 个内置插件、在线升级（SHA-256 + 主机白名单 + DNS 钉扎）。部署形态：Docker Compose（Caddy + PHP-FPM 8.4 + MariaDB 11.4 + s6）、传统 PHP、Windows 脚本。

**V7.4.0 状态**：发布门禁通过、161 tests 全绿、无已知 P0 漏洞。但存在 2 个默认部署可被利用的安全漏洞、2 个数据正确性问题，以及若干 P1/P2 工程债。

## 二、本次升级内容

### P0 级修复（5 项）

| # | 问题 | 影响 | 修复 |
|---|---|---|---|
| 1 | **容器数据暴露**：Caddy 将 `data/`（含 SQL 备份）、`tools/`、`setup/*.sql` 对外提供 | 任何知道路径的人可下载整站数据库 | Caddyfile `respond @private 404` + `.dockerignore` + 3 个 Apache `.htaccess` |

## 三、修复的 Bug

1. **Session 函数命名冲突**：`lib/session.php` 初版定义了 `session_destroy()` 与 PHP 内置函数同名（fatal error），改名 `session_destroy_all()`。

2. **option::set 缓存转义不一致**：`option::set()` 用 `sqladds()` 转义后既写 SQL 又写内存缓存，含引号的值同请求读回是转义后形态。SecretBox 密文不受影响；已列入升级待办（见 [upgrade-backlog.md](./upgrade-backlog.md)）。

3. **CleanUser 未过白名单**：`users.t` 直接拼入 SQL，补 `safe_table_name()`。

4. **mSetFid 全仓零调用**：死代码但仍有注入面（`$kw` + `$fid` 直拼），已修复。
