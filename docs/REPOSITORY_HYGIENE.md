## 文件去留规则

| 内容 | 源码仓库 | 用户部署包 | 本地处理 |
| --- | --- | --- | --- |
| 运行代码、模板、插件、前端资源、安装与迁移 | 保留 | 保留 | 不清理仍有作用的旧升级脚本 |
| `config.php` | 仅保留无凭据的环境变量模板 | 保留该模板 | 个人配置不通过整目录压缩发布 |
| `tests/`、维护脚本、Composer 锁文件 | 保留，用于验证与可重现维护 | 测试与维护工具排除；`tools/migrate.php` 及保护文件例外保留 | `vendor/` 为本地测试依赖，不上传 |
| README、许可证、使用说明与有效截图 | 保留 | README 与许可证保留，开发文档/截图排除 | 不删除百度凭据获取教程图片和页面实际使用的字体、JS/CSS |
| 官方网关零密钥参考实现 | 源码保留 | 排除，部署在独立基础设施 | 不属于桌面/移动版本 |
| `.evolution/`、旧 `upgrade-report/`、过期根审计报告 | 不再跟踪 | 排除 | 已删除确认过期的文件 |
| `.env*`、`key.php`、私钥、SQL 备份、日志、缓存 | 忽略；保留 `.env.example` 模板和目录访问保护文件 | 排除实例数据 | 数据库、配置、用户备份与记录不删除 |
| 一次性测试站点、打包副本和重复下载 | 不上传 | 不进入 | 按固定清单核验路径后清理 |

`.gitignore` 管理将来的入库边界；已跟踪文件必须以删除提交同步才能从远端最新目录消失。`.gitattributes` 管理 `git archive` 的发行内容，不能替代从 Git 源码树中删除废弃文件。`.dockerignore` 单独控制容器构建上下文，已同步补齐本地工具资料、密钥和临时文件排除。
