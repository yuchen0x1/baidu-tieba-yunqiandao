# V5.07：开放 API、签到报表与凭据加密

> 历史 CHANGELOG 记录日期：2026-08-12；未核实独立 Release，不推定正式发布日期。

## 更新内容

- 提供 Bearer Token 认证的状态、签到、复签、健康和日志接口，便于接入外部自动化工具。
- 增加近 30 天签到报表与管理员立即签到、复签入口。
- 增加 Bark、PushPlus 通知，并为百度凭据提供 AES-256-GCM 加密存储及旧明文读取兼容。
- 收紧写请求 CSRF 检查和管理员输入边界，移除废弃加密实现。

## 升级与适用范围

从 5.06 按旧升级链执行 update5.06to5.07.php；升级前备份凭据与数据库，不把该历史阶段的安全措施当作当前已无漏洞的保证。

历史记录描述当时的能力。部署当前版本请以 [README](../README.md) 和 [安装/升级说明](../setup/README.md) 为准；升级前备份数据库。
