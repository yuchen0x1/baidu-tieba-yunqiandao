# V5.07：开放 API、签到报表与凭据加密

> 历史 CHANGELOG 记录日期：2026-08-12；未核实独立 Release，不推定正式发布日期。本文保留本版当时的行为与兼容说明。

## 📢 版本概述

本版本提供 Bearer Token 认证的开放 API、近 30 天签到报表，并将百度凭据改为 AES-256-GCM 加密存储；同时收紧 CSRF 与管理员输入边界。

## ✨ 新增功能

- **开放 API（`api.php`）**：Bearer Token 认证，支持 status/health/sign/retry/health_check/logs 接口，可供青龙面板、n8n、Home Assistant 等外部系统调用。
- **签到报表页**（`templates/admin-stat-chart.php`）：ECharts 折线图展示最近 30 天签到趋势，总执行次数、成功率、最近执行时间卡片；签到看板新增「立即复签」「立即全部签到」按钮。
- **通知渠道**：新增 Bark (iOS) + PushPlus (微信)，共支持 6 种渠道。
- **凭据加密**：BDUSS/STOKEN 加密落库（AES-256-GCM），存量数据升级时自动加密，读取时透明解密，兼容旧明文数据。

## 🔒 安全与兼容性

- CSRF 收紧：POST/PUT/PATCH/DELETE 请求强制要求 Token，不再仅依赖 Referer 回退。
- CSRF Token 密钥：优先使用 `SYSTEM_SALT`，其次使用数据库 `crypto_key`，不再使用硬编码公开字符串。
- 管理员操作参数强转：xorder 插件排序、用户批量操作均强制 int 或正则过滤。
- 移除已废弃的 mcrypt 死代码，替换为 openssl AES-256-GCM。

## 🔄 升级与数据迁移

- 升级脚本 `update5.06to5.07.php`：加密存量 BDUSS、`tieba.latest` 扩展为 VARCHAR(10)、`users` 表加 `created_at`/`last_login`/`auth_version`、生成 `crypto_key`。升级前备份凭据与数据库。
- 历史记录描述当时的能力；不把该历史阶段的安全措施当作当前已无漏洞的保证。部署当前版本请以 [README](../README.md) 和 [安装/升级说明](../setup/README.md) 为准。
