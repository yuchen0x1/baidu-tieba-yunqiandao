# V7.9.0：Webhook 事件中心与调度可靠性升级

本版本把已有 Webhook 能力补齐为可实际运维的事件中心，并修复调度台账、监控时间戳和用户设置参数绑定问题。

## ✨ 新增功能

- 全局设置新增 Webhook 事件推送：启停、事件筛选、测试事件、最近结果摘要。
- 事件载荷包含稳定 `id` 与 `ts`；请求头包含 `X-Webhook-Id`、`X-Webhook-Timestamp`、旧版 `X-Webhook-Signature` 和防重放的 `X-Webhook-Signature-V2`。
- Webhook URL/Secret 加密落库，保存时统一执行公网地址 SSRF 校验。

## 🛠 修复与安全

- 调度进程异常退出后，下一轮调度会把无存活租约的 `running` 台账标记为中断，避免管理页永久显示“开始执行”。
- `cron_last_do` 改为真实时间戳，修复 metrics 端点上次调度时间长期为 0。
- `option::uget/uset` 改用参数绑定并强制整数 UID，避免用户级设置查询受到拼接输入影响。

## 📦 升级说明

- 新增迁移 `007901`：把历史明文 Webhook 地址加密落库（幂等，已加密或无密钥时跳过）；全新安装模板已登记该基线，不会重复提示迁移。
- 现有站点升级后首次打开管理设置页即可看到 Webhook 配置；升级前请备份数据库。
- Webhook 接收方应在 5 分钟时间窗内校验 `X-Webhook-Signature-V2`，并缓存 `X-Webhook-Id` 防止重复处理。
- 正式发布前请先在后台保存设置并发送测试事件，确认接收端返回 HTTP 2xx。
