# V7.5.0：安全与正确性升级

> 本版本修复 2 个默认部署即可被利用的安全漏洞（二阶 SQL 注入、容器数据暴露），并修复 2 个数据正确性问题（论坛名双重转义、跨月漏签）。含 5 个数据库迁移，V7.4.x 站点点「立即更新」后访问 `upgrade.php` 即可自动完成。

## 安全修复

- **二阶 SQL 注入（高危）**：插件配置的贴吧关键词（AI 回帖/自动回帖/帖子监控/封禁）可触发 UNION/盲注读取整库。`findFid`/`mSetFid` 改参数绑定 + 关键词白名单。
- **容器数据暴露**：Caddy 默认将 `data/`（含 SQL 备份、日志）、`tools/`、`setup/*.sql` 对外提供。新增访问控制规则封禁私密路径。
- **敏感配置加密**：18 个选项（通知 Token、SMTP 密码、OAuth Secret 等）加密落库，页面只显示掩码。空提交保持不变，需显式清空。
- **Session 加固**：统一 `use_strict_mode`/`cookie_httponly`/`cookie_samesite=Lax`，登录后再生 session id。
- **2FA 锁定**：同一 UID 10 分钟内失败 5 次锁定 15 分钟。
- **IP 级登录限流**：防多账号喷洒攻击。

## 数据正确性

- **论坛名双重转义修复**：含 `&`/`'` 的吧名此前被 HTML 实体化/转义后落库，导致签到失败。迁移 `007300` 修复历史数据。
- **跨月漏签修复**：签到标记从日号改为完整日期 `Y-m-d`，消除跨月同号误判。迁移 `007301` 强制重签一次。

## 功能改进

- **签到并发 claim**：签到前原子领取贴吧行，结果后释放；进程异常由 TTL 接管，迁移 `007500` 覆盖基础表和动态分表。
- **option 缓存一致性**：全局选项写入改用参数绑定并保留原始运行时值，避免引号/反斜杠配置变形。

- **日报时机**：独立任务 `system_daily_report`（默认关闭），满足时间窗/完成度条件才发送，替代每次签到即发。
- **ECharts 本地化**：断网/内网部署也能出图，保留 CDN 回退。
- **metrics_token 后台配置**：补后台写入口，不再需要手改数据库。
- **删除用户级联清理**：百度凭据、签到历史、OAuth 绑定等随之删除。
- **补缺失索引**：`tieba`/`users_options`/`sign_history`/`login_audit` 复合索引（迁移 `007303`）。
- **日志轮转**：`system.log` 超 10MB 自动归档。
- **LICENSE**：新增 AGPL-3.0 全文，与 composer.json 声明一致。

## 升级说明

- 含 5 个数据库迁移（`007300`~`007303`、`007500`），V7.4.x 站点点「立即更新」后访问 `upgrade.php` 即可自动完成。
- 迁移 `007301` 会重置所有贴吧的签到标记，升级后第一轮签到会重新覆盖全部贴吧（重签一次，不影响历史记录）。
- 迁移 `007302` 会加密 18 个敏感选项的已有明文值。如需回滚，`down` 提供解密回写。
- V7.3.x 以下版本请先升级到 V7.4.0。
