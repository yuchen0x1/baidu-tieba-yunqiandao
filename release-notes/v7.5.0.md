# V7.5.0：安全与正确性升级

> GitHub 发布：2026-11-13（Asia/Shanghai）；代码版本提交：2026-11-13。本文保留本版当时的行为与兼容说明；当前部署只维护网页版，安装与升级以最新文档为准。

## 📢 版本概述

本版本修复 2 个默认部署即可被利用的安全问题（二阶 SQL 注入、容器数据暴露）与 2 个数据正确性问题（吧名双重转义、跨月漏签），并将敏感配置加密落库。含 5 个数据库迁移（`007300`~`007303`、`007500`），V7.4.x 站点点「立即更新」后访问 `upgrade.php` 即可自动完成。

## 🔒 安全与兼容性

- **二阶 SQL 注入（高危）**：插件配置的贴吧关键词（AI 回帖/自动回帖/帖子监控/封禁）可触发 UNION/盲注读取整库。`findFid`/`mSetFid` 改为参数绑定 + 关键词白名单。
- **容器数据暴露**：Caddy 默认将 `data/`（含 SQL 备份、日志）、`tools/`、`setup/*.sql` 对外提供。新增访问控制规则封禁私密路径。
- **敏感配置加密**：18 个选项（通知 Token、SMTP 密码、OAuth Secret 等）加密落库，页面只显示掩码。空提交保持不变，需显式清空。
- **Session 加固**：统一 `use_strict_mode`/`cookie_httponly`/`cookie_samesite=Lax`，登录后再生 session id。
- **2FA 失败锁定**：同一 UID 10 分钟内失败 5 次锁定 15 分钟。
- **IP 级登录限流**：同一 IP 15 分钟内失败达到阈值锁定 15 分钟，防多账号喷洒攻击。

## 🐛 问题修复

- **吧名双重转义**：含 `&`/引号的吧名此前被 HTML 实体化/转义后落库，导致签到失败、健康度对不上。改为原样入库 + 参数绑定，迁移 `007300` 修复历史数据（幂等）。
- **跨月漏签**：签到标记从日号改为完整日期 `Y-m-d`，消除跨月同号误判；迁移 `007301` 一次性重置签到标记。

## ✨ 新增功能

- **签到并发 claim**：签到前对贴吧行原子领取带 TTL 的 claim，结果后释放；异常进程由过期时间自动接管（迁移 `007500`，覆盖基础表和动态分表），避免重复签到请求。
- **日报独立任务**：新增 `system_daily_report`（默认关闭），满足时间窗/完成度条件才发送，替代每次签到即发。
- **删除用户级联清理**：删除用户时同步清理百度凭据、签到历史、OAuth 绑定等关联数据。
- **metrics_token 后台配置**：补后台写入口，不再需要手改数据库。

## 🔧 改进与优化

- **option 缓存一致性**：全局选项写入改用参数绑定并保留原始运行时值，避免引号/反斜杠配置变形。
- **ECharts 本地化**：图表库本地化，断网/内网部署也能出图，保留 CDN 回退。
- **补缺失索引**：`tieba`/`users_options`/`sign_history`/`login_audit` 复合索引（迁移 `007303`）。
- **日志轮转**：`system.log` 超 10MB 自动归档，保留 3 份。
- **工程**：新增 AGPL-3.0 全文 `LICENSE`，与 composer.json 声明一致；`tools/lint.php` 补 CLI 守卫，Web 访问拒绝执行。

## 🔄 升级与数据迁移

- 含 5 个数据库迁移（`007300`~`007303`、`007500`），V7.4.x 站点点「立即更新」后访问 `upgrade.php` 即可自动完成；V7.3.x 以下版本请先升级到 V7.4.0。
- 迁移 `007301` 会重置所有贴吧的签到标记：升级后第一轮签到会重新覆盖全部贴吧（重签一次，不影响历史记录）。
- 迁移 `007302` 会加密 18 个敏感选项的已有明文值；如需回滚，`down` 提供解密回写。
