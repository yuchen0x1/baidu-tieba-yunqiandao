# V7.8.0：并发可靠性、安全响应与限流升级

> GitHub 发布：2026-11-16（Asia/Shanghai）。本文保留本版当时的行为与兼容说明；当前部署只维护网页版，安装与升级以最新文档为准。

## 📢 版本概述

本版本把计划任务锁升级为带租约所有者的模型，修复并发请求下的 API 限流额度超发，并为 Web 入口默认加上安全响应头；同时补齐项目审计、开源对标与升级路线图资料。部署方式仍为统一 Web 包，含一个数据库迁移（`007600`），升级前请备份数据库。

## 🔧 改进与优化

- **计划任务租约锁**：运行锁新增 `running_owner` 租约所有者令牌，旧进程在锁超时被接管后不能释放新进程的锁。
- **租约续期**：新增 `cron::renewLock()`，长任务可在安全边界主动延长自己的租约。
- **任务历史查询**：任务最新运行记录查询改用参数绑定，任务名中的特殊字符不再改变查询语义。

## 🐛 问题修复

- **API 限流并发超发**：限流计数改为原子条件更新 + 唯一键 UPSERT，修复并发请求下的额度超发；达到上限返回 `429` 与 `Retry-After: 60`，限流存储不可用返回 `503 rate_limit_unavailable`。

## 🔒 安全与兼容性

- Web 入口与 `healthz.php` 默认发送 `nosniff`、点击劫持、来源策略及权限策略响应头。
- 保留现有认证、权限矩阵和 API 错误结构；本版没有破坏性 API 字段删除。

- 新增迁移 `007600_cron_lease_owner`，可重复执行，保留既有任务数据；从 V7.7.0 升级时通过根目录 `upgrade.php` 或 `php tools/migrate.php up` 应用，升级前备份数据库。
- 维护报告和研究资料保留在源码仓库，正式 Web 部署包不携带这些文件。
