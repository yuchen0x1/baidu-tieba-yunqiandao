# V7.8.0：并发可靠性、安全响应与限流升级

本版本把计划任务租约、API 限流和默认 Web 安全边界收紧，并补齐项目审计与升级资料。部署方式仍为统一的 Web 包，升级前请备份数据库。

## 并发与调度可靠性

- 计划任务运行锁新增租约所有者令牌，旧进程在锁超时接管后不能释放新进程的锁。
- 新增 `cron::renewLock()`，长任务可以在安全边界主动延长自己的租约。
- 新增数据库迁移 `007600_cron_lease_owner`，可重复执行，保留既有任务数据。
- 任务最新运行记录查询改用参数绑定，避免任务名中的特殊字符改变查询语义。

## API 与 Web 安全

- API 限流使用原子条件更新和唯一键 UPSERT，减少并发请求下的额度超发。
- 达到限额返回 HTTP `429` 和 `Retry-After: 60`；限流存储不可用返回 `503 rate_limit_unavailable`。
- Web 入口和健康检查默认发送 `nosniff`、点击劫持、来源策略及权限策略响应头。
- 保留现有认证、权限矩阵和 API 错误结构；本版没有破坏性 API 字段删除。

## 维护与升级资料

- 新增项目审计、15 个开源项目对标、54 项 EV 路线图和本轮升级报告。
- 维护报告和研究资料保留在源码仓库，正式 Web 部署包不携带这些文件。
- 本轮本机完成 PHPUnit、语法/安全扫描、Secret 扫描、Composer 校验和发布门禁；真实 MariaDB、Docker、多 PHP 版本及生产外部链路仍由 CI 和部署环境验收。

## 升级说明

- 从 V7.7.0 升级时，运行 `php tools/migrate.php up` 或使用站点升级入口应用 `007600`；升级前备份数据库。
- 当前 CLI 环境未加载 `ext-mysqli` 时不能完成本地数据库集成测试；正式发布工作流会在 PHP 8.2 + MariaDB 11.4 服务中执行。
- 租约所有者保护不等于外部副作用恰好执行一次；自动周期续租和真实数据库并发演练仍是后续路线图项目。
