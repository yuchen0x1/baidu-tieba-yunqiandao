# V5.09：安装向导与发布流程

> 历史 CHANGELOG 记录日期：2026-08-30；未核实独立 Release，不推定正式发布日期。本文保留本版当时的行为与兼容说明。

## 📢 版本概述

安装向导升级为响应式卡片布局并补齐引导信息，同时接入基于版本标签的部署包自动发布流程。

## ✨ 新增功能

- 新增按版本 tag 自动构建并发布 Windows 部署包的 GitHub Actions 工作流。

## 🔧 改进与优化

- 安装向导改为响应式卡片布局，新增品牌头部、安全提示和清晰的步骤进度指示器。
- 优化许可协议、环境检查、运行环境选择和站点信息表单的层级、间距与移动端显示。
- 安装页静态资源使用版本号缓存标识，更新后可立即加载最新界面。
- 修复无数据库、空表单和异常步骤参数下的安装页错误，并同步新装数据库版本。

## 🔄 升级与数据迁移

- 通过当时安装/升级向导完成版本同步。历史包中的 Windows 名称属于 PHP 网页部署工具，后续 V7.7.0 改动已取消这种单独分发。历史记录描述当时的能力，部署当前版本请以 [README](../README.md) 和 [安装/升级说明](../setup/README.md) 为准；升级前备份数据库。
