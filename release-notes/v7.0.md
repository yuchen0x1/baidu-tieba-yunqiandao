# 百度贴吧云签到 V7.0

> Git 记录日期：2026-09-06；本次未查到对应 GitHub Release，不把该日期当作发布日期。

> 本文保留本版当时的行为与兼容说明；当前部署只维护网页版，具体以最新安装文档为准。

> 数据库版本 6.6 → 7.0。全新安装直接使用本包安装向导即可；从 6.6 升级请看文末「升级说明」。

## 升级治理

- **统一迁移器**：`schema_migrations` 升级为完整状态模型（checksum/状态/起止时间/批次/错误信息），执行前获取库级迁移锁，防 Web/CLI/容器并发；失败记录可恢复状态，修复后重跑即续走；任一迁移未全部成功绝不更新 `core_version`；已应用迁移被改写时 checksum 校验阻断。
- **版本门禁**：7.0 仅允许从 6.6 升级，更低版本明确阻断并引导先走旧升级链；管理员可访问 `/setup/update6.6to7.0.php`，或服务器执行 `php tools/migrate.php up`。
- **7.0 基线迁移**：校验 6.6 必备核心表齐全（缺失即失败，不猜不跳），幂等补齐调度结构。

## 更新器与发布安全

- 在线更新安装前强制校验发布包 SHA-256（Release `digest` 或 `.sha256` 附件），拿不到可信摘要或哈希不符直接拒绝覆盖安装。
- Docker 更新令牌统一为 `UPDATE_GITEE_TOKEN`（原 `UPDATE_GITHUB_TOKEN` 失效，请同步修改部署环境变量）。
- Composer 平台要求补齐 `ext-zip` / `ext-openssl` / `ext-session`；OpenSSL 与 ZipArchive 在环境检查中升级为「必须」。

## 调度可靠性

- `runOnce` 排程写入持锁完成（finally 保证释放），消除并发交错窗口。
- 渠道告警去重：新增 `cron_notify_interval`（默认 3600 秒，0 关闭），持续失败任务的 Webhook/通知最多每窗口一次；结构化错误日志不受影响。

## 数据库访问收敛

- `ajax.php` / `setting.php` / `api.php` 全部 SQL 参数化（含账号绑定、扫码登录、批量导入），并有 CI 守卫防止插值 SQL 回归。
- 新增 `safe_table_name()` 白名单，`TABLE`/`CON_TABLE` 等来自数据库的动态表名统一过防。

## 开放 API 合同（v1）

- 所有响应携带 `api_version`；错误统一 `{error, code, api_version}` 与稳定错误码（`missing_token`/`rate_limited`/`forbidden_user_token` 等）。
- 方法严格化：方法不符返回 405（此前任何方法都放行）；权限矩阵单一来源驱动门禁与 `action=openapi` 文档。
- ⚠️ 行为变更：此前用 GET 调用 `sign` 等写接口会照常执行，现在返回 405，请改用 POST。

## 插件 ABI

- 启用插件前强制兼容检查（manifest 完整性 + 云签到最低版本 + PHP 最低版本），不满足拒绝启用并给出原因。

## 其他

- `do.php` 新增可选常驻模式：`php do.php --pw=密码 --loop[=间隔秒]`，适合无 crond 的 Windows 部署。
- 修复备份导出丢失 NULL 值的问题（此前恢复后 NULL→'' 静默失真）。
- Linux 兼容：类加载改为大小写无关解析（`class.SignManager.php` 等混合命名在 Linux 容器不再报错）。
- CI 覆盖：MariaDB 11.4 上的迁移/调度/API/备份恢复四条集成链路、Docker 镜像启动冒烟、发布包 SHA-256 打包演练。

## 升级说明（6.6 → 7.0）

1. **备份数据库**并确认备份可恢复。
2. 覆盖程序文件后访问站点，版本门禁会引导到升级入口；或执行 `php tools/migrate.php up`。
3. 5.13 及更早版本请先通过 `setup/update.php` 逐步升级到 6.6，再升级到 7.0。
