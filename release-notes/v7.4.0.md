# V7.4.0：凭据掩码与恢复校验等安全加固

> 本版本聚焦安全加固与可靠性闭环：敏感凭据不再进入页面源码，恢复签到前先实测凭据，长期密码不再写进 HTML，监控端点只接受请求头。无数据库结构变更，V7.3.x 站点点「立即更新」即可全自动完成。

## 敏感凭据保护

- **BDUSS/STOKEN 默认掩码**：百度账号列表不再把完整凭据写进 HTML 源码，默认显示首尾各 4 位的掩码形态。点「显示」才向服务端按需取回一次明文（管理员会话 + CSRF + 账号归属校验），点「隐藏」立即从内存清除。凭据不再随页面源码、浏览器缓存、屏幕共享与截图外泄。
- **计划任务密码不再出现在页面**：签到看板的「立即执行全部签到 / 立即复签失败贴吧 / 手动健康度检查」以及计划任务页的「运行全部计划任务」，改为走管理员会话 + CSRF 的服务端入口（新增 `admin:sign` 白名单分支与 `admin:cron&runall`）。长期密码不会再落进 Web 访问日志、反向代理日志与浏览器历史。
- **metrics 端点只接受请求头**：`metrics.php` 移除 `?token=` 查询参数认证，仅接受 `Authorization: Bearer` 与 `X-API-Token`。检测到旧用法时返回 403 并附迁移指引与 Prometheus 配置示例，便于一次性切换。

## 可靠性闭环

- **恢复签到前先验证凭据**：`restoreBaiduid` 恢复贴吧自动签到前，先按健康检查的同一口径实测 BDUSS。凭据仍失效时直接拒绝恢复并提示重新绑定，成功与失败原因都会在「贴吧与签到」页明确展示。此前的实现只把状态标志改回去，用户会遇到「恢复了、下一轮又停用」的假闭环。
- **消息拉取任务默认停用**：百度 `replyme` / `atme` 接口当前对纯 BDUSS 返回拦截，`system_message_pull` 若保持启用只会每小时白打一次被拒请求并污染任务日志。本版本将其注册为默认停用，消息中心页面同步说明原因与启用路径；数据源恢复后可在「计划任务」页手动启用。

## 界面修复

- **按钮 loading 态恢复可见**：loading 态用透明文字隐藏标签，但 spinner 沿用 `currentColor` 一并变透明，导致按钮只剩禁用态、看不到进行中指示。现改为独立取色变量——浅底按钮用品牌色、实心按钮用白色，深浅主题下均清晰可辨。

## 升级说明

- 无数据库迁移。V7.3.x 站点点「立即更新」即可全自动完成；更早版本请先升级到 V7.3.0 或直接安装本版本完整包。
- 若你用 `metrics.php?token=` 抓取监控，请在升级前把抓取配置改为请求头方式，否则升级后该端点会返回 403 并打印迁移指引。
