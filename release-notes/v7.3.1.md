# V7.3.1：更新通道限流回退与部署可靠性修复

> GitHub 发布日期：2026-11-07（Asia/Shanghai）；代码版本提交：2026-11-06。

> 本文保留本版当时的行为与兼容说明；当前部署只维护网页版，具体以最新安装文档为准。

> 本版本解决普通服务器（无 GitHub Token）检查更新被 GitHub 匿名 API 限流阻断的问题，并提供 do.php --loop 常驻进程的可选优雅重载。无数据库结构变更，从 V7.3.0 在线更新即可。

## 更新通道

- **匿名限流回退**：GitHub API 达到匿名请求限额（HTTP 403/429）时，自动回退读取官方仓库 Release 页面发现最新版本，并按发布脚本固定资产命名获取 Windows 部署包与 SHA-256 校验文件；域名白名单、DNS/重定向逐跳校验与安装前强制摘要校验全部保留，无可信摘要绝不覆盖安装。
- **限流提示明确化**：检查更新与立即更新失败时区分限流场景，显示预计恢复时间、`UPDATE_GITHUB_TOKEN` 提升限额建议与 Release 页手动更新入口，不再笼统提示“无法连接更新服务器”。

## 可靠性与部署

- **do.php --loop 优雅重载（可选，默认关闭）**：部署方设置环境变量 `LOOP_RELOAD_FILE` 后，升级完成会写入重载标记，常驻进程在本轮调度结束后退出（退出码 75），由 s6/systemd/任务计划等进程管理器自动拉起加载新代码；未配置时行为不变，仍需手动重启。Web 进程不执行任何命令、不挂载 Docker socket。
- **CI 修复**：发布包演练 tag 改为符合脚本校验的 `v0.0.0`；Docker smoke 拆卸步骤保留 `DB_PASSWD`；Docker Hub 构建工作流改为从 `version.php` 读取版本号，未配置 Docker Hub 凭据时仅构建不推送。

## 升级说明

- 无数据库迁移。从 V7.3.0 点「立即更新」即可全自动完成（下载 → 校验 → 覆盖 → opcache 重置 → 自动返回首页）；更早版本先升级到 V7.3.0 或直接安装本版本完整包。

## 历史资产名称

当时的 `windows` 命名 ZIP 实际包含 PHP 网页源码。后续 V7.7.0 改动改用通用 Web 包名；此处保留历史记录，不能当作仍在维护的桌面版本。
