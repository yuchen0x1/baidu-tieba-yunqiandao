# V7.2.0：开源与官方服务边界（架构安全批次）

> Git 记录日期：2026-09-07；本次未查到对应 GitHub Release，不把该日期当作发布日期。

> 本文保留本版当时的行为与兼容说明；当前部署只维护网页版，具体以最新安装文档为准。

> 升级方式：在线更新到本版本后，访问 `setup/upgrade.php` 完成升级；或在服务器执行 `php tools/migrate.php up`。
> 本版本**无数据库结构变更**，7.0 及以上均可直接升级。

## 安全修复

- **CSRF 回退盐修复**：此前全新实例（未配置 `SYSTEM_SALT` 且加密密钥未生成）的 CSRF 令牌回退盐为源码内公开常量，攻击者可推算出合法令牌绕过 Referer 门控。现改为首次使用时自动生成随机密钥落库；已配置 `SYSTEM_SALT` 或已有密钥的站点行为不变。
- **发布脚本令牌加固**：清理旧 Release 时 Gitee 令牌从 URL 查询串改为 Authorization 头，避免令牌落入反代/访问日志。
- **仓库 Secret 扫描**：新增 `tools/secret-scan.php`（9 类高信号凭据模式），接入 `composer check`、发布门禁与 CI——任何疑似密钥入库都会让检查直接失败。

## 新能力：官方服务边界（社区版行为不变）

确立「开源实现 ≠ 官方服务能力」的架构边界（详见 `docs/architecture-boundary.md`）：Fork 与自建完全不受影响，官方 AI 配额、模型路由、授权能力只存在于官方基础设施。

- **AI Provider 双形态**：AI 插件新增 Provider 选择——
  - **直连（默认）**：与此前完全一致，站点自带大模型 API Key（加密存储）；
  - **官方 AI 服务**：经官方网关代理，站点**无需持有任何 Provider Key**，模型路由、配额与风控由官方侧裁决。管理页新增网关地址/实例 ID/实例 Secret 接入配置（Secret 加密落库）。
- **官方网关客户端 SDK**（`lib/class.official.php`）：HMAC-SHA256 请求签名 + 时间戳/一次性随机数防重放、短期 Access Token 自动刷新、License 非对称验签（RSA-2048，私钥只在官方侧，客户端仅持公钥）。
- **参考网关**（`official-service/`）：零密钥参考实现（实例认证、防重放、配额限流、Provider 代理），供自建私有网关参考。

## 工具链

- 新增 `tools/official-keygen.php`：官方授权密钥对生成器（私钥仅输出至官方服务器，不入仓库）。
- 发布门禁由 9 项升至 **10 项**（新增 Secret 扫描）。
- `.gitignore` 排除私钥与网关数据目录（`*.pem`、`official-service/keys|data/`）。
- PHPUnit 新增 14 项边界用例（签名固定向量、Token 防篡改/防过期、License 验签、CSRF 盐供应回归）。
