# V7.2.1：升级门禁提示修复

> Git 记录日期：2026-09-07；本次未查到对应 GitHub Release，不把该日期当作发布日期。

> 本文保留本版当时的行为与兼容说明；当前部署只维护网页版，具体以最新安装文档为准。

> 本版本**只有提示文案变化**：无数据库变更、无功能行为变更。7.2.0 站点可升可不升；
> 停留在 7.1.x 及以下的站点建议直接升到本版本。

## 修复内容

- **升级模式不再给出会 404 的第一引导**：此前文件更新完成后，版本门禁页把「点击运行 setup/upgrade.php」作为首选操作。但不少站点（含官方推荐的安全加固）在 Web 服务器上封禁了 `/setup/` 目录（例如 nginx `location ^~ /setup/ { return 404; }`），该链接在这些站点必然 404，用户会被困在升级模式。

- 现在的提示改为两条路径，并把永远可用的命令行排在第一位：
  - **方式一（推荐，任何服务器环境都可用）**：SSH 进入站点根目录执行 `php tools/migrate.php up`；
  - **方式二**：点击运行 `setup/upgrade.php`（并注明：若 `/setup/` 被封禁会 404，请改用方式一）。

## 升级方式

在线更新到本版本后：SSH 执行 `php tools/migrate.php up`，或点击提示页的 `setup/upgrade.php` 链接（若未封禁 `/setup/`），完成版本号同步即可。
