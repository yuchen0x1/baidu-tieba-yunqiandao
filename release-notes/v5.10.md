# V5.10：网络代理与签到策略

> 历史 CHANGELOG 记录日期：2026-09-03；未核实独立 Release，不推定正式发布日期。本文保留本版当时的行为与兼容说明。

## 📢 版本概述

本版本加入全局与账号级网络代理、打码平台接入和多项签到策略开关，降低部署环境与风控对签到的影响。

## ✨ 新增功能

- **全局网络代理**：支持 HTTP(S) 与 SOCKS5（远程 DNS 解析），签到、扫描、TBS、扫码绑定等请求统一走代理工厂。
- **账号级代理覆盖**：百度账号列表页可为单个账号配置独立代理（`http://host:port` 或 `socks5://user:pass@host:port`），留空跟随全局，`off` 单独禁用。
- **打码平台接入**：目前支持超级鹰；绑定账号遇到验证码时自动识别并重试一次，识别失败自动退还题分。
- **模拟客户端版本号 options 化**：签到设置页可改，百度更新客户端后无需改代码即可切换版本号。
- **签到随机抖动（sign_jitter）**：在签到间隔基础上随机追加等待，随机化请求节奏。
- **签到乱序开关（sign_shuffle）**：默认随机乱序执行签到队列。
- **开源致谢**：新增板块（`index.php?mod=thanks`），登记本项目所依赖的全部开源项目与作者。

## 🔄 升级与数据迁移

- 数据库版本 5.09 → 5.10：`baiduid` 表新增 `proxy` 列，`options` 表新增 11 项默认设置；请执行 `update5.09to5.10.php` 完成升级，升级前备份数据库。外部代理/打码服务需要自行配置。
- 历史记录描述当时的能力，部署当前版本请以 [README](../README.md) 和 [安装/升级说明](../setup/README.md) 为准。
