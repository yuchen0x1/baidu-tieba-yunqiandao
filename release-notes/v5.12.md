# V5.12：账号中心、个人 API 与插件自动化

> 历史 CHANGELOG 记录日期：2026-09-03；未核实独立 Release，不推定正式发布日期。

## 更新内容

- 新增账号中心、个人 API Token、签到历史与日历，个人接口按用户隔离。
- 增加自动回帖、发主题帖、楼中楼回复、云点赞及更多通知渠道。
- 提供用户修改密码、多邀请码、邮件群发与定时数据库备份。
- 加入失效账号停用、签到客户端指纹轮换，并强化参数化查询及插件安装校验。

## 升级与适用范围

从 5.11 执行 update5.11to5.12.php，增加个人 Token 等字段和历史结构。该版本合并记录原 CHANGELOG 的两个 5.12 开发批次。

历史记录描述当时的能力。部署当前版本请以 [README](../README.md) 和 [安装/升级说明](../setup/README.md) 为准；升级前备份数据库。
