# V5.12：账号中心、个人 API 与插件自动化

> 历史 CHANGELOG 记录日期：2026-09-03；未核实独立 Release，不推定正式发布日期。本文保留本版当时的行为与兼容说明。本文件合并原 CHANGELOG 的两个 5.12 开发批次。

## 📢 版本概述

本版本新增账号中心、逐用户 API Token 与签到历史日历，插件自动化扩展至云端回帖、发主题帖、楼中楼与云点赞，通知渠道扩至 11 个，并加入运维工具（多邀请码、邮件群发、定时备份）。

## ✨ 新增功能

- **账号中心**（`index.php?mod=account`）：集中展示每个绑定账号的健康状态、贴吧数量、当日签到结果、代理配置与失效恢复入口，附近 7 天签到趋势。
- **逐用户 API Token**：个人设置生成/撤销，数据库只存 SHA-256 哈希；旧全局 Token 完全兼容；用户 Token 严格隔离 status/sign/retry/health/logs/calendar。
- **签到历史与日历**：新增 `sign_history` 表记录每个贴吧每次签到的结果，个人 90 天热力图页与 `api.php?action=calendar` 接口。
- **云端自动回帖插件 `ver4_reply`**：目标贴吧 + 回帖内容库（随机选取）+ 每吧限量 + 每账号每日上限 + 随机间隔 + 按天去重（独立日志表）；接口 `c/c/post/add`（tiebaclient 签名，继承账号级代理，触发频率限制自动终止本轮）。
- **自动发主题帖**（ver4_reply 1.1）：目标贴吧 + 标题库 + 内容库随机选取、每吧限量、每账号每日发帖上限，接口 `c/c/thread/add`，与自动回帖共用间隔与代理；回帖/发帖日志表新增 `type` 列区分（旧表自动补列）。
- **楼中楼回复**：回帖可按可调比例（0-100%）随机进入主题帖指定楼层回复，楼层经 `c/f/pb/page` 获取、`quote_id` 参数提交。
- **云点赞插件 `ver4_like`**：按贴吧配置、多账号、每吧限量、随机间隔，走贴吧客户端接口并继承账号级代理。
- **通知渠道扩展至 11 个**：新增钉钉群机器人（支持加签）、企业微信、飞书、WxPusher、ntfy（自托管 HTTPS 实例）。
- **失效账号自动停用**：BDUSS 健康检查连续失败达到阈值（可配 1-20 次）后自动停止该账号全部贴吧签到并推送提醒；账号所有者与管理员均可一键恢复。
- **插件在线安装**：仅允许 `https://gitee.com` 的 ZIP 下载链接，禁止跨域重定向、限制 50MB；上传安装与在线安装统一走安全提取器（单根目录、Zip Slip 防护、拒绝覆盖、兼容 `仓库-main` 归档结构）。
- **用户自主修改密码**：个人设置页修改密码（验证当前密码、6-64 位校验），改密成功后旧会话自动失效。
- **多邀请码管理**：`admin:invite` 页面批量生成（数量/可用次数/有效期/备注）、启用停用、删除、用量统计；注册流程支持多邀请码模式（`invites` 表原子核销）。
- **邮件群发**：用户管理页向全部留有邮箱的用户发送 HTML 邮件，支持 `{name}`/`{site}` 变量。
- **定时数据库备份**：每日导出全部数据表到 `data/backups`（Apache 由 .htaccess 拦截直接下载），保留份数可配、可选邮件通知站长；工具箱可一键注册任务、立即备份。
- **客户端指纹轮换**：签到设置开关（默认开启），开启后每次请求随机 `_client_type` 与 `_client_id`/`_phone_imei`。

## 🔒 安全与兼容性

- 移除工具箱「运行 SQL」功能（任意 SQL 执行面），同时移除遗留的不可达死代码。
- 新增 `wmysql::pquery` 参数化查询支撑，插件管理、计划任务、用户管理、找回密码、账号代理、个人设置、开放 API 日历/日志、登录审计、健康探针等后台 SQL 汇聚点迁移至预处理语句。
- 插件全部 GET 动作（启用/禁用/更新/卸载/重置/安装）增加 `valid_plugin_id` 白名单校验；自定义分表名强制 `^[a-z0-9_]{1,64}$` 白名单；批量修改用户组强制 int 转换；后台添加用户与站内注册统一用户名/邮箱白名单；计划任务动作名统一白名单。
- `tools/lint.php` 弃用 shell 拼接改为 `token_get_all` 进程内语法检查；`LoginGuard::auditLogin` 移除函数内 `$_POST` 直读；账号恢复参数增加数字白名单。
