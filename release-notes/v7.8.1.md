# V7.8.1：多语言管理台

> GitHub 发布：2026-11-17（Asia/Shanghai）。本文保留本版当时的行为与兼容说明；当前部署只维护网页版，安装与升级以最新文档为准。

## 📢 版本概述

网页控制台新增中文/English 双语支持：按浏览器或系统语言自动选择，也可手动切换并持久化。核心界面即时更新语言；贴吧内容、账号数据和接口字段保持原样。本版无数据库迁移。

## ✨ 新增功能

- **自动语言检测**：按浏览器/系统语言自动选择界面语言。
- **手动切换与持久化**：中文/English 可在控制台手动切换，设置持久保存。
- **界面即时翻译**：导航、设置、通知状态和表单提示即时更新语言。

## 🔒 安全与兼容性

- 贴吧内容、账号数据和接口字段保持原样；本版不改变 API 行为与数据库结构。

## 📦 下载与安装

| 文件名 | 适用环境 | 说明 |
|---|---|---|
| tieba-cloud-sign-web-v7.8.1.zip | Web（PHP + MySQL/MariaDB） | 通用网页版部署包 |
| tieba-cloud-sign-web-v7.8.1.zip.sha256 | Web（PHP + MySQL/MariaDB） | 部署包 SHA-256 校验文件 |
| tieba-cloud-sign-update-v7.8.1.json | Web（PHP + MySQL/MariaDB） | 在线更新元数据清单 |

- 首次安装：参考 [README](https://github.com/yuchen0x1/baidu-tieba-yunqiandao#readme) 与 [安装/升级说明](https://github.com/yuchen0x1/baidu-tieba-yunqiandao/blob/main/setup/README.md)。
- 已安装用户：后台「系统更新」点「立即更新」在线升级；或手动覆盖文件后访问根目录 `upgrade.php`。

## 🔄 升级与数据迁移

- 无数据库迁移；V7.8.0 站点在线更新后访问 `upgrade.php` 同步版本即可。
