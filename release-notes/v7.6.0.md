# V7.6.0：调度可靠性与任务运维升级

计划任务现在支持搜索、状态筛选和分页历史，手机端也能直接查看任务与操作。本版同时修复配置加密后计划任务密码及全局代理密码不可用的问题，并完善失败重试与备份恢复体验。

## 任务管理

- 按任务名、描述或文件查找任务，筛选已启用、已禁用、最近失败、运行中和已到期任务。
- 运行历史可按任务、结果和时间区间查询，并支持分页；旧记录缺失开始时间时会明确标注。
- 手机端纵向展示任务信息与操作，保留浅色、深色主题、日志展开和运行顺序调整。
- 运行失败或任务被占用时给出明确提示，运行中避免重复点击，卸载前保留确认步骤。

## 执行与恢复

- 修复加密配置后的计划任务密码认证及全局代理密码使用，兼容旧明文配置。
- 自动调度在领取任务时同时检查启用与到期状态，避免依据过时列表重复执行已经排程的周期任务。
- 每项任务的最大重试次数真正生效，范围 0–20，0 表示不自动重试；等待按 1、2、4…倍增长，单次最多一天。
- 完善异常后的解锁与重试恢复，结束记录保留开始时间，长中文日志不会因字符截断而写入失败。
- SQL 备份明确声明 utf8mb4，改善导入工具默认编码不同时中文、emoji 和序列化配置的恢复兼容性。

## 升级说明

- 从 7.5.0 升级没有新增数据库结构迁移；仍需通过在线更新后的升级入口完成版本同步。升级前请备份，常驻调度进程升级后需重启，或使用已配置的优雅重载机制。
- 管理员的任务变更改为 POST + CSRF 表单，旧的任务管理 GET 写链接会返回 405；请使用计划任务页操作。原有 `do.php` 与开放 API 入口保留。
- 单项“运行/重试”属于管理员主动执行，可执行未到期或已禁用任务，但仍需获得运行锁；“运行到期任务”遵守启用与到期状态。
- 一次性任务仍在执行后删除。运行锁仍使用超时接管，应将超时设置为大于实际最长任务耗时；不保证外部副作用只发生一次。
- 发布包提供 SHA-256 校验与更新清单；未提供 detached 发布签名，强制要求签名的站点不能使用该包直接在线覆盖。
