# V7.6.0：调度可靠性与任务运维升级

> GitHub 发布：2026-11-13（Asia/Shanghai）；代码版本提交：2026-11-13。本文保留本版当时的行为与兼容说明；当前部署只维护网页版，安装与升级以最新文档为准。

## 📢 版本概述

计划任务支持搜索、状态筛选和分页历史，手机端也能直接查看与操作；同时修复配置加密后计划任务密码与全局代理密码不可用的问题，完善失败重试、解锁恢复和备份编码兼容。本版无新增数据库结构迁移。

## ✨ 新增功能

- **任务搜索与筛选**：按任务名、描述或文件查找任务，筛选已启用、已禁用、最近失败、运行中和已到期任务。
- **分页运行历史**：运行历史可按任务、结果和时间区间查询并支持分页；旧记录缺失开始时间时明确标注。
- **手机端适配**：任务信息与操作纵向展示，保留浅色/深色主题、日志展开和运行顺序调整。

## 🐛 问题修复

- **加密配置后的密码使用**：修复 V7.5.0 配置加密后，`do.php` 认证、异步调度和全局代理仍读取密文的问题；继续兼容历史明文配置。
- **重复执行周期任务**：自动调度在领取任务时原子校验启用与到期状态，不再依据过时快照重复运行已排程任务。

## 🔧 改进与优化

- **重试配置生效**：单任务 `max_retry` 真正生效（范围 0–20，0 表示不自动重试），等待按 1、2、4…倍增长，单次最多一天；一次性任务保留执行后删除的行为。
- **异常恢复**：首次运行日志写入失败也会解锁；异常返回失败，手动重试取得锁后才清零计数；结束记录保存开始时间，长中文日志按 UTF-8 边界截断。
- **备份编码**：SQL 备份明确声明 utf8mb4，改善导入工具默认编码不同时中文、emoji 和序列化配置的恢复兼容性。
- **任务页提示**：运行失败或任务被占用时给出明确提示，运行中避免重复点击，卸载前保留确认步骤。

## 🔒 安全与兼容性

- 管理页写操作改为 POST + CSRF 令牌，旧的任务管理 GET 写链接返回 405；请使用计划任务页操作。原有 `do.php` 与开放 API 入口保留。

## 🔄 升级与数据迁移

- 从 V7.5.0 升级没有新增数据库结构迁移，仍需通过升级入口完成版本同步；升级前备份，常驻调度进程升级后需重启，或使用已配置的优雅重载机制。
- 单项「运行/重试」属于管理员主动执行，可执行未到期或已禁用任务，但仍需获得运行锁；「运行到期任务」遵守启用与到期状态。

## ⚠️ 已知问题

- 运行锁仍使用超时接管，应将超时设置为大于实际最长任务耗时；不保证外部副作用只发生一次。
- 发布包提供 SHA-256 校验与更新清单，未提供 detached 发布签名；强制要求签名的站点不能使用该包直接在线覆盖。
