# V7.2.2：一键全自动升级

> 从本版本起，升级只需在后台点一次「立即更新」：文件更新后自动完成备份、迁移与缓存清理，无需 SSH。

## 全新升级体验

- **点一次「立即更新」即全自动**：在线更新器覆盖文件后，自动跳转到根目录新入口 `upgrade.php` 并自动执行：**自动备份数据库 → 自动运行统一迁移器 → 自动清理 opcache**，完成后一键进入新版本。
- **根目录一键升级入口 `upgrade.php`**：
  - 与 `index.php` 同级，**不受 `/setup/` 被 Web 服务器安全规则封禁的影响**（v7.1.1～v7.2.1 的 `setup/upgrade.php` 在这类站点会 404，这是此前多次升级卡死的根因）；
  - 管理员登录 + CSRF 令牌双重校验；
  - 迁移过程流式输出，具备防并发锁与失败记录，失败后修复问题重新执行即可；
  - 也可不经更新器直接访问 `upgrade.php` 完成版本同步（例如手动覆盖文件后）。

## 其他改进

- **升级前自动备份**：每次升级自动生成 `pre-upgrade_*.sql`（保留最近 3 份，独立于定时备份的保留额度），存放于 `data/backups`。
- **修复**：升级入口触发 `SYSTEM_DEV` 重复定义 PHP 告警的问题（根目录与 `setup/upgrade.php` 入口同时受益）。
- **升级门禁提示改版**：「方式一」改为管理员一键升级按钮；SSH 命令行降为「方式二」。

## 升级方式

- **常规（推荐）**：后台「系统更新」→ 点「立即更新」→ 全自动完成。
- **手动覆盖文件后**：浏览器访问站点根目录的 `upgrade.php`，点击「开始升级」即可。
- 说明：若部署使用 `do.php --loop` 常驻进程，升级完成后请重启该进程加载新代码；普通计划任务部署无需任何操作。
