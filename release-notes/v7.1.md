# 百度贴吧云签到 V7.1

> 数据库版本与 7.0 一致，升级后 `core_version` 变为 7.1，无破坏性变更；从 7.0 在线更新或覆盖部署后即可使用，老配置无需迁移。

## 全站页面体验重设计

- 用户侧与管理侧全部页面统一「页头横幅」：小字眉题 + 标题 + 状态标签 + 常用操作按钮。此前只有一半页面有页头，插件页是裸标题，现在所有页面观感一致：状态一眼可见，常用操作就在手边。
- 页面提示、空数据状态、表格工具条、表单分段编号（①②③…）按统一规范收敛。

## 目标贴吧可以勾选了（自动回帖 / 云点赞 / 帖子监控）

- 三个插件的「目标贴吧」不再需要手动输入贴吧名：直接从你在「贴吧与签到」同步的贴吧列表里**勾选**即可。
- 支持**搜索过滤**（贴吧多时快速定位）、「全选筛选结果」「清空」和已选计数。
- 勾选自动写入下方文本框；也可以继续手动输入未同步的贴吧名，两边双向同步，格式不变，老配置无需迁移。

## 重点页面改进

- **工作台**：按时段向你问好（早上好/晚上好 + 昵称），新增「连续签到」统计卡；管理员的系统健康、服务器信息折叠为次级区域，不与日常内容混排。
- **AI 发帖/回帖**：运行状态、配置来源、账号数在页头一目了然；**AI 总开关直接在页头切换、即时保存**。
- **个人设置**：单张长表单拆为「基本信息 / 签到策略 / 通知与报告 / API 与安全」四张卡片两栏排布，修改密码独立成卡。
- **账号中心**：近 7 天签到结果改为紧凑表格（一天一行）。
- **贴吧与签到**：账号切换改为下拉选择，贴吧列表新增搜索与分页（每页 50 条），保存按钮常驻页面底部，改完即存不用来回滚。
- **计划任务 / 插件管理**：排序支持**拖拽**（拖完自动重排顺序值，点保存生效）。
- **用户管理**：勾选用户后底部浮现批量操作条，新增用户搜索框。
- **成就勋章**：新增「已解锁 / 待解锁」筛选；**签到排行**：我的排名直接显示在页头，前三名带奖牌标识。
- **帖子监控**：设置拆为「监控规则 / 推送与通知渠道」两张卡片，通知渠道字段只在你选中该渠道时展开。
- **公告栏管理**：挂载点从多选列表改为复选按钮组，新增「预览效果」。
- **管理侧**：签到看板的立即执行任务提升到页头；邀请码、双因素认证、系统更新、工具箱等页面统一新骨架。

## 侧边栏重排

- 分组顺序调整为：核心页（WORKSPACE）→ 插件功能（PLUGINS）→ 个人设置与致谢（PREFERENCES）→ 管理区（OPERATIONS）→ 扩展（EXTENSIONS）。
- AI 发帖/回帖与自动回帖相邻，不再被设置页隔开。

## 修复

- 修复部分列表条目（如「近 7 天签到结果」、开源致谢名单）被拆成逐行竖排的排版错误。
