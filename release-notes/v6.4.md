# V6.4：安全与数据正确性、AI 草稿

> Git 记录日期：2026-09-05；本次未查到对应 GitHub Release，不把该日期当作发布日期。本文保留本版当时的行为与兼容说明。
> 数据库版本 6.3 → 6.4（无核心表结构变更）。站长建议：升级后在「设置中心 → 系统」重新保存一次开放 API Token，即可从旧明文存储自动转为哈希存储（新旧两种存储形态均正常认证，不强制）。

## 📢 版本概述

本版本修复 6 处高危安全与数据正确性问题，收紧多项输入边界与 Token 存储，并为 AI 插件补齐人设模板、半自动发帖草稿与内容审查拦截记录（ver4_ai 插件 2.1 → 2.2）。后续版本还有进一步安全修复。

## 🔒 安全与兼容性

- **邮箱验证接口未认证 SQL 注入**：`index.php?mod=verify&token=` 的 token 未做格式校验直接拼 SQL，访客可盲注；现按生成格式（40 位十六进制）严格校验后放行。
- **「重签出错吧」跨用户数据重置 + 万级 N+1**：共享贴吧表中按他人 id 区间逐行循环且 UPDATE 缺失 uid 条件，单次点击可能清掉其他用户的签到状态；现改为单条带 uid 的参数化 UPDATE（仅重置本人出错贴吧）。
- **百度接口错误消息二阶注入**：签到失败的 `error_msg` 含引号时状态落库静默失败、贴吧无法进入复签队列；fid/状态/错误消息全部参数化。
- **管理员侧注入面**：用户管理的 `NOT IN (...)` 列表与数据库备份表名拼接强制 int 转换 + 表名白名单。
- **CSRF 硬化**：请求携带 token 但校验失败时直接拒绝，不再静默降级到 Referer 校验（未携带 token 的旧链接仍走原 Referer 规则，兼容不变）。
- **全局 API Token 与 metrics Token 哈希存储**：保存后仅落库 SHA-256，认证端同时兼容哈希与升级前旧站明文形态；`metrics.php` 与 `api.php` 双消费点同步。

## 🔧 改进与优化

- **CSV 导出上限**：签到日志导出被分页上限钳制为 200 行且无任何提示；上限提升至 5000 行，UI 分页不受影响。
- **性能与信息泄露收敛**：签到日志/健康检查的高频建表 DDL 加进程级守卫（含表缺失自愈重试）；「立即签到」响应不再把全站统计回给普通用户（改本人数据）；管理后台状态面板全表扫描改 SQL 聚合；`option` 类 `plugin_` 分支与用户设置 uid 全部参数化/强转；开放 API `update` 动作对个人 Token 返回 403；账号绑定缺参从空白页改为 JSON 错误；日志筛选 LIKE 通配符转义。
- **排行榜隐私开关修复**：`option::uget` 参数顺序颠倒导致查询恒为空，勾选「隐藏昵称」后昵称仍公开；已修正。
- **界面**：「重签出错吧」增加确认弹窗（说明只重置出错项、不影响已签成功项）；贴吧绑定缺参提交返回明确 JSON 错误提示。

## ✨ 新增功能（AI 插件 ver4_ai 2.1 → 2.2）

- **自定义人设模板**：个人面板可把调好的人设另存为「我的模板」（上限 20 个、同名覆盖），人设下拉新增「我的模板」分组，支持选用与删除。
- **半自动发帖模式**：开启后计划任务到点不再自动发布，而是为每个目标吧一次生成 3 条候选（逐条过敏感词 + 近 7 天去重），存入「发帖草稿箱」由用户挑选发布或丢弃；发布前校验账号归属，失败保留草稿可重试；候选 7 天未处理自动清理、每人上限 15 条；与全自动模式并存互不影响。
- **内容审查拦截记录**：用户页新增敏感词/重复跳过单独列表（最近 20 条，仅本人账号），便于排查人设与敏感词配置。
- 插件内发帖/回帖/日志/建表函数上移至 `ver4_ai_client.php`，计划任务与用户页共用一份实现。
