# V6.4：安全与数据正确性、AI 草稿

> Git 记录日期：2026-09-05；本次未查到对应 GitHub Release，不把该日期当作发布日期。

## 更新内容

- 修复邮箱验证输入、跨用户复签重置、错误消息写入、排行榜隐私及管理员输入边界。
- 改善 Token 哈希存储、CSRF 无效令牌拒绝、统计访问范围和 CSV 导出上限。
- AI 用户页增加自定义人设模板、半自动草稿候选与内容审查拦截记录。

历史记录描述当时的能力。部署当前版本请以 [README](../README.md) 和 [安装/升级说明](../setup/README.md) 为准；升级前备份数据库。
