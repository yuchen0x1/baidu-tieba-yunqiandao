# V7.2.3：升级完成自动返回首页

> GitHub 发布：2026-11-05（Asia/Shanghai）；代码版本提交：2026-09-07。本文保留本版当时的行为与兼容说明。

## 📢 版本概述

从「立即更新」到回到站点全程零手动确认：文件更新 → 自动备份 → 自动迁移 → 自动清缓存 → **自动返回首页**。

## 🔧 改进与优化

- **升级完成后自动返回首页**：一键升级成功页 3 秒后自动跳转（保留「立即进入」按钮可立即跳转）；访问 `upgrade.php` 时发现无需升级的分支同样自动返回首页。
- 升级失败页**不**自动跳转，以便完整查看错误信息与修复指引。

## 📦 下载与安装

- 本版本的 [GitHub Release](https://github.com/yuchen0x1/baidu-tieba-yunqiandao/releases/tag/v7.2.3) 页仅存档源码，未附带部署包资产；当时的部署包按旧发布流程经 Gitee 分发。
- 首次安装：参考 [README](https://github.com/yuchen0x1/baidu-tieba-yunqiandao#readme) 与 [安装/升级说明](https://github.com/yuchen0x1/baidu-tieba-yunqiandao/blob/main/setup/README.md)。
- 已安装用户：后台「系统更新」点「立即更新」在线升级；或手动覆盖文件后访问根目录 `upgrade.php`。

## 🔄 升级与数据迁移

- 后台「系统更新」→ 点「立即更新」→ 等待自动完成即可；或手动覆盖文件后访问 `upgrade.php`。无数据库迁移。
