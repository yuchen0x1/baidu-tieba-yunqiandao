# V7.2.3：升级完成自动返回首页

> GitHub 发布日期：2026-11-05（Asia/Shanghai）；代码版本提交：2026-09-07。

> 本文保留本版当时的行为与兼容说明；当前部署只维护网页版，具体以最新安装文档为准。

> 从「立即更新」到回到站点全程零手动确认：文件更新 → 自动备份 → 自动迁移 → 自动清缓存 → **自动返回首页**。

## 改进

- **升级完成后自动返回首页**：一键升级成功页 3 秒后自动跳转（保留「立即进入」按钮可立即跳）；访问 `upgrade.php` 时发现无需升级的分支同样自动返回首页。
- 升级失败页**不**自动跳转，以便完整查看错误信息与修复指引。

## 升级方式

后台「系统更新」→ 点「立即更新」→ 等待自动完成即可；或手动覆盖文件后访问 `upgrade.php`。
