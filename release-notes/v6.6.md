# V6.6：移动网页适配与工作台快捷操作

> Git 记录日期：2026-09-05；本次未查到对应 GitHub Release，不把该日期当作发布日期。

## 更新内容

- 主要页面表单在小屏上纵向排列，记录和草稿列表采用受控横向滚动。
- 统一日志、任务和插件状态样式，减少旧 HTML 字体标签造成的视觉不一致。
- 工作台提供立即签到、绑定账号、签到记录和数据分析快捷入口。

## 升级与适用范围

从 6.5 执行 update6.5to6.6.php 同步版本。这里的移动端指手机浏览器，不是 Android/iOS 独立 App。

历史记录描述当时的能力。部署当前版本请以 [README](../README.md) 和 [安装/升级说明](../setup/README.md) 为准；升级前备份数据库。
