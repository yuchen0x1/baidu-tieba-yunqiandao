# V6.6：移动网页适配与工作台快捷操作

> Git 记录日期：2026-09-05；本次未查到对应 GitHub Release，不把该日期当作发布日期。本文保留本版当时的行为与兼容说明。
> 数据库版本 6.5 → 6.6，无任何表结构变更，纯界面版本；CSS 缓存戳随版本号自动更新，浏览器会强制拉取新样式。

## 📢 版本概述

本版本深化移动端适配并统一视觉细节，工作台新增首屏快捷操作。这里的移动端指手机浏览器，不是 Android/iOS 独立 App。

## ✨ 新增功能

- **工作台首屏快捷操作**：Hero 区新增常用操作行——「立即签到」（一键为我的全部账号签到，实时显示已签/失败/等待统计与反馈，未绑定账号时自动禁用）、「绑定百度账号」「签到记录」「数据分析」直达入口。

## 🔧 改进与优化

- **移动端深度适配**：10 个主要页面在 375px 视口下横向溢出清零（程序化审计驱动）；AI 发帖/回帖设置表格新增响应式布局，手机上逐行堆叠；「最近执行记录」「发帖草稿箱」「内容审查拦截」表格统一接入玻璃滚动容器；移动端内联定宽输入控件自动转全宽。
- **视觉细节统一**：全仓 22 处遗留 `<font color>` 标签清零，统一为 `cs-badge` 状态徽章与文本色工具类（覆盖 AI 用户页/插件管理/计划任务/双因素认证/账号中心/贴吧封禁日志）；管理页插件状态、计划任务运行状态徽章与新版页面风格一致。

## 🔄 升级与数据迁移
