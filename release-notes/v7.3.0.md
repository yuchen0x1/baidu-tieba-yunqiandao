> 本版本新增签到成长数据记录与日报展示，并集中加固外发请求、ZIP 解压、发布更新通道和部署兼容性。
> 数据库版本 7.2.3 → 7.3.0：在线更新后访问根目录 `upgrade.php` 完成迁移，或执行 `php tools/migrate.php up`。升级前请备份数据库。

## 签到成长指标

- **成长数据记录**：签到历史新增本次获得经验、今日签到排名与贴吧等级字段；成功签到时保存客户端接口返回的成长数据。
- **贴吧列表展示**：在账号贴吧列表中展示最近一次成功签到获得的经验与签到排名，并与近 30 天成功率一起呈现。
- **签到日志展示**：签到记录新增成长经验列，同时显示今日签到排名与贴吧等级；无法确认经验值时明确显示“经验未知”，不再使用固定经验值代替。
- **每日签到日报**：日报新增当日累计成长经验、总体成功率和失败贴吧摘要；优先使用用户配置的通知渠道，未配置或未送达时回退用户邮箱，仅在确认送达后记录为已发送。

## 安全修复

- **外发请求 SSRF 防护**：Webhook、Bark 与 ntfy 目标仅允许解析到公网 IPv4/IPv6 地址；拒绝内网、保留、特殊用途地址及混合公私 DNS 结果。连接固定到已校验的解析结果，并禁用重定向与环境代理，避免校验后转向内网地址。
- **ZIP 路径穿越防护**：插件与通用 ZIP 解压流程在写入前校验条目路径，拒绝 `../` 穿越、绝对路径和包含空字节的条目。
- **更新器目标校验**：在线更新仅接受受信任的 GitHub API 与 Release 资产域名；重定向逐跳复核，GitHub 令牌仅发送给指定的官方 Release API 路径。

## 可靠性与部署

- **运行环境兼容**：缺少 ctype 扩展时提供兼容函数；Docker 镜像补装 ctype，并统一服务启动脚本换行格式。
- **检查工具兼容**：全仓语法扫描在 tokenizer 不可用时回退到 `php -l`；数据库集成测试支持通过 `TCS_IT_DB_HOST` 指定数据库主机。
- **发布通道迁移**：项目源码与 Windows 部署包改由 GitHub Releases 发布；版本标签触发构建、生成 SHA-256 校验文件并创建 GitHub Release。

- 在线更新完成后访问根目录 `upgrade.php`，或执行 `php tools/migrate.php up`。升级失败时可修复问题后重新执行迁移。
