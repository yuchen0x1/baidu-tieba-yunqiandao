# V5.08：基于正式 Release 的在线更新

> 历史 CHANGELOG 记录日期：2026-08-29；未核实独立 Release，不推定正式发布日期。本文保留本版当时的行为与兼容说明。

## 📢 版本概述

系统更新页改为读取正式 Release 检测更新，支持管理员在线更新源码，并提供独立检查脚本与 API 接口。

## ✨ 新增功能

- 系统更新页读取当前仓库正式 Release，按版本号检测更新，不再把开发中的 commit 当作稳定版本。
- 检测到更新时显示版本说明、Release 页面和部署包下载入口，支持管理员在线更新源码。
- 新增 `api.php?action=update` 版本检查接口和 `windows/check-update.ps1` 独立检查脚本。

## 🔒 安全与兼容性

- 在线更新强制 HTTPS 并限制可信下载域名，更新前再次确认最新 tag。
- 更新时保留 `config.php`、`key.php`、环境变量文件、安装锁和数据库；失败时清理临时文件。
- 支持 `UPDATE_GITHUB_TOKEN` 提高 API 速率限制，支持 `SSL_CERT_FILE` / `CURL_CA_BUNDLE` 修复 Windows PHP CA 配置。

## 🔄 升级与数据迁移

- 按旧升级链部署。此条记录当时的更新能力，强制摘要校验、可选签名与故障恢复由后续版本加入，不归入本版。历史记录描述当时的能力，部署当前版本请以 [README](../README.md) 和 [安装/升级说明](../setup/README.md) 为准；升级前备份数据库。
