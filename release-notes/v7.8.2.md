## 📢 版本概述

本次更新收紧在线更新的覆盖保护，让 Web 升级先落好数据库备份，并让 Docker Compose 部署的站点配置与数据在容器重建后保留。本版本没有可下载附件；见下方发布状态更正。本版没有新增数据库结构迁移。

## 🔧 改进与优化

- **在线更新串行保护**：同一站点一次只允许一个覆盖操作；覆盖前校验部署包内版本与核心入口，防止不匹配的包进入站点。
- **升级前先备份**：Web 数据库升级先保存数据库备份，备份失败时停止迁移。
- **静态资源缓存重校验**：静态资源改为按请求重新验证缓存。
- **系统更新页标注**：明确展示 Web 部署包及校验状态。
