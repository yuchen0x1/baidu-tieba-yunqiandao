# V7.3.2：扫码绑定自动确认与成功提示

> 本版本让扫码绑定百度账号实现全自动确认：手机扫码授权后无需手动点击，系统自动检测授权结果、提示绑定成功并刷新账号列表。无数据库结构变更。

## 扫码绑定

- **自动轮询授权状态**：扫码绑定弹窗打开期间，系统自动检测百度授权进度——"等待扫码" → "已扫码，请在手机上确认授权" → "成功绑定"全程自动提示，无需手动点击「点击绑定」。
- **绑定成功自动反馈**：授权确认后自动完成账号入库，弹窗内显示绿色"成功绑定百度账号：xxx"提示并弹出成功通知，约 1.2 秒后自动刷新页面，账号列表立即出现新绑定的账号。
- **异常场景明确提示**：二维码失效显示"二维码已失效，请刷新页面重新扫码"；重复绑定等业务错误停止轮询并展示具体原因；不再输出"Continue"等含糊的内部状态文案。
- 「点击绑定」按钮保留，作为手动立即检查一次的入口；关闭弹窗即自动停止轮询。

## 问题修复

- **个人设置页无法打开**：V7.3.0 起个人设置的"签到策略"模板把全局变量 `$i` 用作循环计数器，破坏了系统设置缓存，页面提示"系统发生内部错误"。现已改用独立变量名，并为设置写入增加防御：缓存被破坏时自动降级为空数组，不再产生致命错误。

## 升级说明

- 无数据库迁移。V7.3.1 站点点「立即更新」即可全自动完成；更早版本先升级到 V7.3.0 或直接安装本版本完整包。
