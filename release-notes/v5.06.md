# V5.06：通知、登录防护与签到日志

> 历史 CHANGELOG 记录日期：2026-08-12；未核实独立 Release，不推定正式发布日期。

## 更新内容

- 新增 Server酱、Telegram、Webhook 和邮件通知，签到失败和账号凭据失效可触发提醒。
- 增加登录失败锁定及登录审计，签到、复签和健康检查接入运行日志。
- 启用 HTTPS 与 TLS 证书验证，错误提示减少 SQL、路径及调用栈泄露；旧密码可在成功登录后升级。
- 提供存储引擎与索引升级脚本，默认关闭调试插件。

## 升级与适用范围

旧站按 setup/update.php 中的顺序执行 update5.05to5.06.php；该版本仅有历史开发记录，未核实独立 Release。

历史记录描述当时的能力。部署当前版本请以 [README](../README.md) 和 [安装/升级说明](../setup/README.md) 为准；升级前备份数据库。
