# V6.3：帖子监控、AI 联动与数据运营

> Git 记录日期：2026-09-04；本次未查到对应 GitHub Release，不把该日期当作发布日期。

## 更新内容

- 帖子监控支持关键词、排除词、个人渠道、实时/每日汇总及命中历史，可选联动 AI 回帖。
- 百度账号页增加关注贴吧、签到进度、分组、批量操作、统一代理与 CSV 导出。
- 增加用户每周报告、历史数据保留与清理任务，丰富多维数据分析。
- 改善玻璃界面、深浅主题和降级显示，修复部分监控与 AI 执行问题。

## 升级与适用范围

从 5.13 执行 update5.13to6.3.php，补齐默认配置并注册任务。历史通知汇总及失败去重缺陷的修复在后续 V7.7.0 记录中单列。

历史记录描述当时的能力。部署当前版本请以 [README](../README.md) 和 [安装/升级说明](../setup/README.md) 为准；升级前备份数据库。
