# V6.3：帖子监控、AI 联动与数据运营

> Git 记录日期：2026-09-04；本次未查到对应 GitHub Release，不把该日期当作发布日期。本文保留本版当时的行为与兼容说明。
> 数据库版本 5.13 → 6.3（无核心表结构变更）。本版本起恢复「每批次同步：版本号 + 更新日志 + Release」的发版节奏。

## 📢 版本概述

本版本新增帖子监控插件及其与 AI 回帖的联动，AI 面板下沉为用户个人功能，签到引擎补齐时段窗口与重试退避，并加入数据保留清理、每周报告与多维数据分析。

## ✨ 新增功能

- **帖子监控插件（ver4_monitor 1.0 → 1.4）**：个人面板配置目标贴吧与关键词，定时扫描最新主题帖并推送命中提醒——支持排除关键词、监控全部新帖模式、实时推送或每日汇总（附各吧命中统计）、个人通知渠道（Server酱/TG/Bark/PushPlus/Webhook/ntfy，未配置回退站点渠道）、命中帖首楼页内预览、命中历史记录。
- **监控命中联动 AI 自动回帖（1.4）**：命中后由 AI 读取首楼上下文生成回复并自动发布（用户开关 + 每日上限 1-20），复用 AI 配置/人设/内容风格与站长敏感词、内容去重防护，命中表展示回帖状态。
- **AI 面板 2.0**：发帖/回帖下沉为用户个人面板功能（个人 Key AES 加密存储，可选站点共享配置回退）；内容安全双重防护（站长敏感词全站预检 + 近 7 天同账号内容去重）；AI 内容风格定制（emoji 允许/禁止、字数偏好）与话题标签自动附加。
- **百度账号页增强套件**：「我的贴吧」关注吧列表（等级/经验/今日签到状态 + 30 分钟缓存）、今日签到进度条、账号分组管理与筛选、聚合操作（全部/选中账号立即签到、一键刷新贴吧列表）、统一代理入口、最高吧等级 Top3 摘要、「关注 N 吧 · 已签 M」徽章、我的贴吧 CSV 导出。
- **签到引擎**：签到时段窗口（支持跨零点）、失败智能重试退避（按 2 的幂间隔）、客户端指纹轮换默认开启。
- **数据保留与自动清理**：工具箱可配签到历史/任务运行历史/批量签到日志/插件执行记录保留天数（0=永久），新增 `system_cleanup` 每日清理计划任务（升级脚本自动注册，工具箱可手动触发）。
- **每周签到报告**：个人设置开启并选择推送日，`system_weekreport` 经用户个人通知渠道推送近 7 天签到汇总/成功率/失败原因 Top3（6 天防重、无记录不打扰）。
- **数据分析页**：7/30/90/365 天多维分析（成功率趋势/吧维度对比/失败原因 TOP/时段分布/账号健康对比）+ 报表 CSV 导出。

## 🔧 改进与优化

- **Glass v5 玻璃拟态深化**：环境光斑升级为品牌紫罗兰光谱（深浅双主题）；提示条/列表/折叠/表格容器玻璃化；深色主题残留旧配色清理；修复 BS5 变量导致深色表格白底白字、alert 实色刺眼的问题；下拉菜单玻璃化；不支持 backdrop-filter 时自动回退高不透明玻璃。

## 🐛 问题修复

- 帖子监控排除关键词失效（cron 使用未定义变量 `$excludeWords`，选项从未被读取）。
- 双因素认证（admin:totp）页面空白（control.php 缺渲染分支）。
- 健康度列窄屏被挤成竖排；监控页个人通知渠道输入框窄屏裁切；贴吧列表序号列改为面板内行号。
- 数据中心 IP 风控提示、AI 账号过滤空配置误产出 `[0]` 导致全部账号被跳过（`strlen('0')` 陷阱）。

## 🔒 安全与兼容性

- 插件与核心 40 处 SQL 汇聚点参数化加固（pquery 预处理）；weltolk 插件设置页存储型 XSS 回显转义；用户选项写入迁移参数化。

## 🔄 升级与数据迁移
