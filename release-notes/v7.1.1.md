# 百度贴吧云签到 V7.1.1

> Git 记录日期：2026-09-07；本次未查到对应 GitHub Release，不把该日期当作发布日期。

> 本文保留本版当时的行为与兼容说明；当前部署只维护网页版，具体以最新安装文档为准。

> 修复版本：包含 V7.1 全部内容。数据库版本统一为 7.1.1，无破坏性变更。

## 修复

- **修复从 7.0 升级被版本门禁阻断的问题**：V7.1 无数据库结构变更，但从 7.0 更新文件后，站点会提示「数据库中的云签到版本(7.0)与文件版本(7.1)不符，且未找到对应的升级脚本」而无法使用。

## 新增：通用升级入口

- 新增 `setup/upgrade.php`：无专用逐版本升级脚本时，**6.6 及以上任意版本均可通过它一键直升当前版本**——同一迁移器、同一状态记录，具备防并发锁与失败恢复，失败后修复问题刷新重试即可。
- 版本门禁行为：存在专用脚本（如 6.6 → 7.0 的 `update6.6to7.0.php`）时仍优先引导专用脚本；否则引导通用入口；6.6 以下仍要求先用 `setup/update.php` 逐步升级。
- 命令行 `php tools/migrate.php up` 一直是可用路径，不受影响。

## 已升级到 V7.1 后被阻断的站点怎么办

任选其一：

1. 直接访问 `https://你的站点/setup/upgrade.php`，以管理员身份登录后点击执行，即可完成升级。
2. 在服务器上运行 `php tools/migrate.php up`。
3. 按在线更新流程更新到 V7.1.1，站点会自动引导完成升级。
