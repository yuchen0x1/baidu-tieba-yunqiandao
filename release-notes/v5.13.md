# V5.13：调度、监控与迁移基础设施

> Git 记录日期：2026-09-03；本次未查到对应 GitHub Release，不把该日期当作发布日期。

## 更新内容

- 增加任务运行历史、到期调度、失败退避重试及后台运行状态展示。
- 提供 HMAC Webhook 事件推送、API 速率限制和接口文档入口。
- 增加结构化运行日志、Prometheus 监控和深度健康检查。
- 加入数据库迁移工具、插件清单与回滚流程、管理员 TOTP，并建立国际化基础结构。

## 升级与适用范围

从 5.12 执行 update5.12to5.13.php 或当时适用的迁移流程；本版包含调度表结构变化。国际化为基础结构，不能理解为已提供多语言完整界面。

历史记录描述当时的能力。部署当前版本请以 [README](../README.md) 和 [安装/升级说明](../setup/README.md) 为准；升级前备份数据库。
