# V5.13：调度、监控与迁移基础设施

> Git 记录日期：2026-09-03；本次未查到对应 GitHub Release，不把该日期当作发布日期。本文保留本版当时的行为与兼容说明。

## 📢 版本概述

本版本建立调度引擎、可观测性与数据库迁移体系三项基础设施，并加入 Webhook 事件推送、API 限流、插件规范与管理员双因素认证。

## ✨ 新增功能

- **调度引擎**：任务级运行历史（`task_runs`）、跨进程防重入锁、按 `nextrun` 调度、失败指数退避重试（`cron_max_retry`/`cron_retry_backoff`）、任务中心增强（状态徽标/下次执行/耗时/一键重试）。
- **Webhook 事件推送**：新增 `lib/class.webhook.php`，任务失败等事件推送自定义 URL（HMAC-SHA256 签名 `X-Webhook-Signature`），curl 优先、stream 回退。
- **开放 API 增强**：`api.php` 新增按 Token 的滑动窗口限流（超限 429）、`webhook_test`（管理员测试推送）、`openapi`（接口文档）。
- **可观测性**：结构化 JSON 日志（`data/log/system.log`）、Prometheus 端点（`metrics.php`，Token 认证）、深度健康检查（`healthz.php?mode=deep`：cron 新鲜度/错误堆积）。
- **数据库迁移体系**：新增 `tools/migrate.php status|up|down` 与 `schema_migrations` 表；首个幂等迁移 `001001_v513_scheduler.php` 覆盖 V5.13 全部结构。
- **插件规范**：manifest 清单校验（缺失 name/version/author 标记不完整）；覆盖安装自动备份到 `plugins/.rollback` 且失败自动回滚，支持手动恢复。
- **管理员双因素认证（TOTP）**：新增 `lib/class.totp.php`（RFC 6238，兼容 Google/Microsoft Authenticator），管理员登录二次验证；`admin:totp` 页生成密钥/链接、启用/关闭。
- **工程收尾**：`tools/lint.php` 新增高危模式扫描（eval/废弃 mysql_* 硬失败，addslashes/命令调用警告，`@lint-ignore` 豁免），随 CI 自动执行。
- **国际化骨架**：新增 `lib/i18n.php` 与 `lang/zh-CN.php`，`I18N::t()` 词条化调用（登录页示例接入）。

## 🔄 升级与数据迁移

- 数据库版本 5.12 → 5.13：`cron` 表新增 `enable/nextrun/retry/max_retry/last_status/last_duration/running/running_at`，新建 `task_runs`、`api_rate_limits` 表，补齐调度/API/可观测性/Webhook 选项。
- 升级路径：访问 `/setup/update5.12to5.13.php`（自动迁移+自删），或使用 `php tools/migrate.php up` 统一迁移（幂等，可重复执行）。升级前备份数据库。
