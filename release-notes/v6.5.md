# V6.5：明细导出、监控统计与健康趋势

> Git 记录日期：2026-09-05；本次未查到对应 GitHub Release，不把该日期当作发布日期。本文保留本版当时的行为与兼容说明。
> 数据库版本 6.4 → 6.5（无核心表结构变更）；健康度快照表随健康检查自动创建并积累，无需手工操作。

## 📢 版本概述

数据分析页新增三项能力：贴吧维度明细 CSV 导出、帖子监控命中统计、账号健康度趋势图。

## ✨ 新增功能

- **吧维度明细导出**：数据分析页新增「导出吧明细 CSV」，按当前统计区间输出每个贴吧的成功/失败/总计/成功率/最近状态/最近签到时间/最近消息。
- **监控统计纳入报表**：新增「监控命中趋势」区块（每日命中数面积图）与每吧命中数/联动 AI 回帖数 Top 表（近 7/30/90/365 天跟随区间筛选）；帖子监控插件未安装时自动隐藏，不影响页面。
- **账号健康度趋势**：新增 `tc_baiduid_health_snapshot` 每日快照表（每账号每天一条，取当天最后一次健康检查结果，随既有健康检查计划任务自动积累，无需新增计划任务）；分析页新增「账号健康度趋势」图（每日正常账号数柱状 + 正常率折线，空白天自动补齐）。

## 🐛 问题修复

- 修复原「导出报表 CSV」未跟随管理员控制模式（CON_UID）视角的问题——管理员查看某用户数据时，导出的也是该用户的数据。

## 🔄 升级与数据迁移

- 从 6.4 执行 `update6.4to6.5.php` 同步版本；健康趋势需在健康检查实际运行后才逐步积累，不生成历史假数据。历史记录描述当时的能力，部署当前版本请以 [README](../README.md) 和 [安装/升级说明](../setup/README.md) 为准；升级前备份数据库。

## 🧪 验证结果

- 新增 `ReportStatsTest` 4 项（监控表缺失容错、Top/趋势聚合、健康趋势空白天填充与参数绑定、健康快照 REPLACE 参数绑定），全量 77 项测试通过。
