# V5.11：批量账号导入、找回密码与邮箱验证

> 历史 CHANGELOG 记录日期：2026-09-03；未核实独立 Release，不推定正式发布日期。本文保留本版当时的行为与兼容说明。

## 📢 版本概述

本版本面向账号与注册体验：一次粘贴多行凭据批量导入百度账号、注册邮箱自助找回密码，以及可选的注册邮箱验证。

## ✨ 新增功能

- **批量导入百度账号**：账号页支持多行粘贴 BDUSS（可带 STOKEN，兼容 `BDUSS=xxx;STOKEN=yyy` 等格式），自动校验 Cookie、识别账号名并尊重配额与重复添加策略，单次最多 50 行。
- **找回密码**：登录页新增"忘记密码"入口，访客可通过注册邮箱自助重置（一次性令牌 30 分钟有效，5 分钟请求频率限制）。
- **注册邮箱验证（可选开关）**：开启后新注册用户需点击邮件中的验证链接才能登录，验证页支持 5 分钟一次的重发；未开启时老账户登录不受影响。
- **访客页面**：新增可访客访问的 `index.php?mod=lostpw` 找回密码页与 `index.php?mod=verify` 邮箱验证页。

## 🔄 升级与数据迁移

- 数据库版本 5.10 → 5.11：`options` 表新增 `reg_mail_verify` 默认项；请执行 `update5.10to5.11.php` 完成升级，升级前备份数据库。邮件功能依赖可用发信配置。
- 历史记录描述当时的能力，部署当前版本请以 [README](../README.md) 和 [安装/升级说明](../setup/README.md) 为准。
