# V5.11：批量账号导入、找回密码与邮箱验证

> 历史 CHANGELOG 记录日期：2026-09-03；未核实独立 Release，不推定正式发布日期。

## 更新内容

- 支持一次粘贴多行 BDUSS/STOKEN 导入百度账号，校验账号、配额及重复绑定，单批最多 50 行。
- 新增注册邮箱找回密码，一次性令牌有效期及请求频率受限。
- 提供可选注册邮箱验证、验证邮件重发和访客找回密码页面。

## 升级与适用范围

从 5.10 执行 update5.10to5.11.php；邮件功能依赖可用发信配置。

历史记录描述当时的能力。部署当前版本请以 [README](../README.md) 和 [安装/升级说明](../setup/README.md) 为准；升级前备份数据库。
